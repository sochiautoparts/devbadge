Quick Start

1

Install DevBadge

Install via pip:

pip install devbadge
2

Generate Badges

Create badges for your GitHub profile:

devbadge generate --user YOUR_USERNAME --all --theme dracula
3

Add to README

Reference the generated SVGs in your profile README:

![Commits](./badges/commits.svg) ![Languages](./badges/languages.svg) ![Stats](./badges/stats.svg)
4

Pro Features (Optional)

Activate Pro for weather, Spotify, animations, and custom colors:

# Weather badge (wttr.in, no API key) devbadge generate --user YOU --badge weather --city "San Francisco" # Spotify now-playing devbadge generate --user YOU --badge spotify --spotify-token "your_token" # Custom colors devbadge generate --user YOU --all --color accent=#ff6600
5

Auto-Update (GitHub Action)

Create .github/workflows/update-badges.yml:

name: Update Badges on: schedule: - cron: '0 * * * *' workflow_dispatch: jobs: update: runs-on: ubuntu-latest permissions: contents: write steps: - uses: actions/checkout@v4 - uses: sochiautoparts/devbadge@main with: github-token: ${{ secrets.GITHUB_TOKEN }} badge: commits,languages,stats,activity theme: dracula
